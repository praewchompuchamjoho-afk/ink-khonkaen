# INK KHON KAEN: เว็บรวมร้านสักลายขอนแก่น

เว็บ HTML/CSS/JavaScript ล้วน ไม่ต้องติดตั้งแพ็กเกจ

## เปิดใน Visual Studio Code
1. เปิดโฟลเดอร์นี้ใน VS Code
2. ติดตั้งส่วนขยาย Live Server แล้วคลิกขวาที่ `index.html` เลือก Open with Live Server
   (ปุ่ม ใช้ตำแหน่งปัจจุบัน ใช้ได้เมื่อเปิดผ่าน localhost หรือ https เท่านั้น)
3. ต้องต่ออินเทอร์เน็ต เพราะแผนที่ (Leaflet + OpenStreetMap) และฟอนต์โหลดจากเว็บ

## ไฟล์
- `index.html` โครงหน้า | `style.css` สไตล์ | `app.js` การทำงาน
- `shops-data.js` ข้อมูลร้านทั้ง 15 แห่ง (แก้หรือเพิ่มได้)
- `images/` โฟลเดอร์รูปของร้านเดิม (อ้างชื่อไฟล์ใน `shops-data.js`)
- `config.js` ใส่ URL ที่เก็บข้อมูลร้านที่ส่งเข้ามา
- `apps-script/Code.gs` โค้ดฝั่งเก็บข้อมูลบน Google Sheets (ฟรี)

## ตั้งค่าให้ร้านเพิ่มข้อมูลเองได้ (ฟรี)
1. สร้าง Google Sheet ใหม่ เมนู Extensions > Apps Script
2. วางโค้ดจาก `apps-script/Code.gs` แล้วบันทึก
3. Deploy > New deployment > ประเภท Web app: Execute as = Me, Who has access = Anyone
4. คัดลอก URL ของ Web app ไปใส่ใน `config.js` ที่ `API_URL`
5. ร้านที่ส่งมาจะเข้าแท็บ `Shops` สถานะ `pending` ตรวจสอบแล้วเปลี่ยนเป็น `approved` ร้านจึงแสดงบนเว็บ
6. แก้โค้ดใน Apps Script แล้วต้อง Deploy เวอร์ชันใหม่ทุกครั้ง

ถ้ายังไม่ตั้งค่า ฟอร์มจะแสดงข้อมูลเป็น JSON ให้คัดลอกส่งผู้ดูแลแทน

## ความปลอดภัยที่ใส่ไว้
- ข้อมูลที่ร้านส่งมาไม่แสดงทันที ต้องอนุมัติก่อน
- หน้าเว็บแสดงข้อความผ่านฟังก์ชัน esc() และรับเฉพาะลิงก์ที่ขึ้นต้น http/https
- ฝั่ง Apps Script ตรวจพิกัด จำกัดความยาว และกันสูตรในชีต
- ช่องดักบอท (honeypot) และต้องติ๊กยืนยันความเป็นเจ้าของร้าน

## ข้อจำกัด
- ยังพิสูจน์ไม่ได้ว่าคนที่ส่งเป็นเจ้าของร้านจริง ผู้ดูแลควรตรวจกับร้านก่อนอนุมัติ
- ยังไม่มีระบบรีวิวและให้ดาวของผู้ใช้เว็บ มีแต่คะแนน Google ที่ใส่ไว้เป็นข้อมูล
- แผนที่ OpenStreetMap ใช้ได้กับงานเล็ก ถ้าผู้ใช้มากให้ใช้ผู้ให้บริการแผนที่ตามเงื่อนไขของเขา
- ข้อมูลเดิมจาก Google Maps ณ 20 พ.ย. 2569 ตรวจกับร้านก่อนใช้จริง

## หน้ารายละเอียดร้าน รูปภาพ และคำแนะนำร้าน
- กดชื่อร้านหรือปุ่ม "ดูรายละเอียด" (ทั้งในรายการและบนหมุดแผนที่) จะเปิดหน้าต่างรายละเอียด มีรูปได้หลายรูป (ร้านเดิมสูงสุด 12 รูป)และคำแนะนำร้าน
- ร้านเดิม: ใส่ `about:"..."` (ไม่เกิน 300 ตัวอักษร) และ `photos:["images/ไฟล์1.jpg","images/ไฟล์2.jpg"]` ใน `shops-data.js` แล้ววางไฟล์รูปในโฟลเดอร์ `images` ถ้าไม่ใส่ about ระบบสรุปให้จากสไตล์และคะแนนที่มี
- ร้านใหม่: ฟอร์มมีช่องคำแนะนำร้านและเลือกรูปได้ 1-6 รูป ระบบย่อรูปในเบราว์เซอร์ก่อนส่ง รูปเก็บใน Google Drive โฟลเดอร์ `INK KHON KAEN photos` ของบัญชีเจ้าของชีต
- หลังแทนที่ `Code.gs` ใน Apps Script ต้อง (1) เลือกฟังก์ชัน `authorize` แล้วกด Run 1 ครั้งเพื่ออนุญาตเข้าถึง Drive (2) Deploy > Manage deployments > แก้ไข > Version: New version > Deploy (URL เดิม ไม่ต้องเปลี่ยน `config.js`)
- ชีตจะมีคอลัมน์ `about` และ `photos` เพิ่ม (K, L) สคริปต์ใส่หัวคอลัมน์ให้เอง

## ข้อควรระวังเรื่องรูปภาพ
- รูปที่ส่งมาถูกบันทึกลง Drive ทันทีแม้สถานะยังเป็น pending ตรวจรูปในชีต (ลิงก์ในคอลัมน์ photos) ก่อนอนุมัติ และลบรูปของร้านที่ไม่อนุมัติออกจากโฟลเดอร์ใน Drive
- ตรวจว่ารูปไม่ละเมิดลิขสิทธิ์และไม่เห็นหน้าบุคคลโดยไม่ได้รับอนุญาต
- บัญชี Google Workspace ของโรงเรียนหรือองค์กรอาจห้ามแชร์ไฟล์แบบ "ทุกคนที่มีลิงก์" ถ้ารูปไม่ขึ้นบนเว็บ ให้ใช้บัญชี Google ส่วนตัวสร้างชีตและสคริปต์

## เวลาเปิด-ปิด และรีวิว (เพิ่มใหม่)
### 1) ใช้ได้เลย ไม่ต้องตั้งค่า Google
- เวลาเปิด-ปิดที่พิมพ์เอง: ใน `shops-data.js` ใส่ `hours:"ทุกวัน 10:00-23:00"` หรือ `hours:["จ. 10:00-20:00","อ. ปิด"]`
- รีวิวจากผู้ใช้เว็บ: ในหน้าต่างรายละเอียดร้านมีฟอร์มให้เลือกดาวและเขียนความคิดเห็น ข้อมูลเข้าแท็บ `Reviews` ในชีตเป็น `pending` เปลี่ยนเป็น `approved` เพื่อให้แสดง
- ต้องวางโค้ด `apps-script/Code.gs` ใหม่ รัน `authorize` 1 ครั้ง แล้ว Deploy เวอร์ชันใหม่ (Manage deployments > New version)

### 2) (ไม่บังคับ และอาจมีค่าใช้จ่าย) เวลาเปิด-ปิด คะแนน และรีวิวจาก Google แบบสด ต้องมีบัญชี Google Cloud + บัตรสำหรับ billing
- โหมดฟรีเป็นค่าเริ่มต้น เว็บไม่เรียก Google API เลย จะเปิดใช้ได้เมื่อใส่ `GOOGLE_LIVE: true` ใน `config.js` และตั้ง `PLACES_KEY` ตามขั้นตอนด้านล่าง
1. เข้า console.cloud.google.com สร้างโปรเจกต์ เปิด Billing แล้วเปิดใช้ **Places API (New)**
2. สร้าง API key ที่ APIs & Services > Credentials แล้วจำกัดสิทธิ์ (API restrictions) ให้ใช้ได้เฉพาะ Places API (New)
3. ตั้งงบเตือน (Billing > Budgets & alerts) และจำกัดโควตาต่อวันของ Places API (New) ในเมนู Quotas เพื่อกันค่าใช้จ่ายเกิน
4. ใน Apps Script: Project Settings (ไอคอนเฟือง) > Script properties > Add script property ชื่อ `PLACES_KEY` ค่าเป็น API key
5. รัน `authorize` ใหม่ แล้ว Deploy เวอร์ชันใหม่
- ค่าใช้จ่ายคิดตามการใช้งาน ฟิลด์เวลาเปิด-ปิด คะแนนและรีวิวอยู่ในกลุ่มราคาที่สูงกว่าข้อมูลพื้นฐาน ดูอัตราและส่วนที่ใช้ฟรีรายเดือนปัจจุบันที่หน้าราคาของ Google Maps Platform
- `Code.gs` จำกัดการเรียก Google ไม่เกิน 200 ครั้งต่อชั่วโมง (แก้ที่ `MAX_GOOGLE_PER_HOUR`)
- ถ้าจับคู่ร้านผิดหรือไม่เจอ ใส่ `placeId:"ChIJ..."` ของร้านนั้นใน `shops-data.js` (หา Place ID ได้จากเครื่องมือ Place ID Finder ของ Google)
- ข้อกำหนดของ Google: ห้ามเก็บหรือแคชเนื้อหา Places (ยกเว้น Place ID) จึงดึงสดทุกครั้งและไม่บันทึกลงชีต ต้องแสดงที่มา "Google Maps" และชื่อผู้รีวิวใกล้รีวิว Google ได้สูงสุด 5 รีวิวต่อร้าน และเขียนรีวิว Google ผ่านเว็บนี้ไม่ได้ ให้ผู้ใช้เขียนที่ Google Maps โดยตรง
- ต้องมีหน้าข้อกำหนดการใช้งานและนโยบายความเป็นส่วนตัวที่เข้าถึงได้สาธารณะ มีแม่แบบ `terms.html` ให้แล้ว ใส่ช่องทางติดต่อของคุณในไฟล์นั้น
- กราฟ "Popular times" ที่เห็นใน Google ไม่มีใน Places API
- คะแนน Google ใน `shops-data.js` เป็นค่าที่พิมพ์ไว้เมื่อ 20 พ.ย. 2569 เมื่อเปิดระบบนี้ แสดงค่าสดในหน้ารายละเอียดแทน

## ค้นหาสไตล์/ความสนใจ
- ช่องค้นหาค้นได้ทั้งชื่อร้าน สไตล์ คำภาษาอังกฤษ (เช่น minimal, scar, cover up, yant) คำอธิบายร้าน และพิมพ์ผิดเล็กน้อยได้ ผลลัพธ์เรียงตามความตรง และร้านที่มีสไตล์ใกล้เคียงจะติดป้าย "ใกล้เคียง"
- รายการสไตล์ทั้งหมด (34 อย่าง แบ่ง 3 กลุ่ม) คำพ้อง และสไตล์ใกล้เคียง อยู่ที่บล็อก `STYLE_CATALOG` ต้นไฟล์ `app.js` เพิ่มสไตล์ใหม่ได้โดยเพิ่ม 1 แถว
- ใส่สไตล์ให้ร้านเดิมที่ `styles:[...]` ใน `shops-data.js` โดยใช้ชื่อให้ตรงกับใน `STYLE_CATALOG` ปุ่มกรองด้านบนจะแสดงเฉพาะสไตล์ที่มีร้านใช้อยู่จริง
- ร้านใหม่เลือกสไตล์ได้สูงสุด 12 อย่าง (แก้ที่ `MAX_STYLES` ใน `app.js` และเลข 12 ใน `Code.gs`)
